# SubManager

SubManager is a responsive subscription management dashboard for tracking recurring services, monthly spending, upcoming renewals, and subscription status.

## Features

- Dashboard summary cards for monthly spend, active services, and upcoming renewals
- Six-month spending chart with current spending highlighted
- Searchable and filterable subscription table
- Add subscriptions with inline validation and local browser persistence
- Dashboard, Subscriptions, Analytics, and Settings pages
- Light and dark themes with responsive mobile navigation

## Tech stack

- React 19
- Vite
- React Router
- Recharts
- Tailwind CSS 4
- Lucide icons

## Setup

Requirements: Node.js and npm.

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL printed by Vite.

To create a production build, run:

```bash
npm run build
```

Run the unit tests with:

```bash
npm test
```

Subscriptions and theme preference are stored in this browser's local storage.
